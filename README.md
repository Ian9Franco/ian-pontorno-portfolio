# Ian Pontorno — Portfolio

Personal portfolio for **Ian Franco Collada Pontorno**, a Full-Stack Developer & Growth Engineer based in Buenos Aires, Argentina.

The site presents selected software projects, professional experience, and education in English and Spanish. It includes a dedicated engineering case study for [MIM](https://github.com/Ian9Franco/MIM), Ian's current flagship project.

## Selected work

- **MIM** — Desktop and web platform for modpack management, diagnostics, file recovery, and cloud collaboration.
- **Elseframe Comics** — Interactive comic reader and creative authoring tools.
- **Smart Scan** — Local file explorer focused on semantic search and multimedia workflows.

Additional projects cover product tooling, image processing, entertainment, business websites, and data-driven applications.

## Technology

- Next.js and React
- TypeScript
- Tailwind CSS
- Framer Motion
- Vercel Analytics

## Local development

```bash
npm ci
npm run dev
```

Production verification:

```bash
npm run typecheck
npm run build
```
